# MES 시스템 프로젝트 생성 프롬프트

아래 내용대로 프로젝트를 구성해줘.

## 1. 프로젝트 개요

- 목적: MES(Manufacturing Execution System) 관리자용 웹 화면
- 범위(1단계): **로그인/권한 없이**, 사이드바 메뉴 클릭 → 페이지 이동까지만 동작하는 골격을 만든다. 사내 폐쇄망 운영이라 인증은 후순위로 미룬다.
- 백엔드: Java 21, Spring Boot, Gradle, MyBatis
- 프론트엔드: React (Vite), React Router
- DB: MySQL (MyBatis 사용이므로 실제 DB 연결 없이도 구조는 완성)

## 2. 백엔드 요구사항

### 2.1 레이어 구조 (메뉴 1개당 아래 6개 파일 생성)

```
Controller → Service(interface) → ServiceImpl → DAO(Mapper interface) → Mapper.xml → Domain(VO/DTO)
```

- Controller: HTTP 요청/응답만 처리, 비즈니스 로직 없음
- Service: 인터페이스로 계약만 정의
- ServiceImpl: 실제 로직 위치, `@Transactional` 여기서 관리
- DAO: `@Mapper` 붙은 인터페이스
- Mapper.xml: 실제 SQL, `src/main/resources/mapper/{중분류}/{메뉴}Mapper.xml`
- Domain: VO(DB 컬럼 1:1), 검색조건 DTO, 등록/수정 요청 DTO 분리

### 2.2 패키지 구조 — 중분류(대분류 카테고리) 기준 폴더링

```
com.mes
 ├─ MesApplication.java
 ├─ common
 │   ├─ response      (ApiResponse, PageResponse)
 │   ├─ exception     (GlobalExceptionHandler, BusinessException, ErrorCode)
 │   └─ config        (MyBatisConfig, CorsConfig)
 ├─ menu              (사이드바 메뉴 트리 반환 전용, 횡단 관심사)
 │   ├─ controller / service / service.impl / dao / domain
 ├─ base              (기준정보)
 │   ├─ controller / service / service.impl / dao / domain
 ├─ monitoring        (모니터링)
 ├─ production        (생산관리)
 ├─ condition         (조건관리)
 ├─ quality           (품질관리)
 └─ equipment         (설비관리)
```

각 중분류 패키지 하위에 소속 메뉴 개수만큼 Controller/Service/ServiceImpl/DAO/Domain 세트를 만든다 (아래 4번 메뉴 목록 참고).

### 2.3 REST API 규칙

- URL 패턴: `/api/{중분류}/{메뉴}`  예) `/api/base/user`, `/api/quality/cpk`
- 표준 응답 포맷:

```json
{
  "success": true,
  "code": "OK",
  "message": null,
  "data": { }
}
```

- 1단계 범위에서는 각 메뉴 Controller는 **목록 조회 API 1개만** 우선 구현 (`GET /api/{중분류}/{메뉴}` → 더미/빈 데이터라도 정상 응답 형태로 반환). CRUD 나머지는 다음 단계.

### 2.4 메뉴 트리 API (사이드바용, 가장 먼저 만들 것)

```
GET /api/menu/tree
```

응답 예시:

```json
{
  "success": true,
  "data": [
    {
      "category": "기준정보",
      "path": "/base",
      "menus": [
        { "name": "사용자관리", "path": "/base/user" },
        { "name": "거래처관리", "path": "/base/vendor" }
      ]
    }
  ]
}
```

1단계에서는 DB 조회 대신 서버 코드 내 고정 리스트(하드코딩)로 반환해도 된다. 나중에 `tb_menu` 테이블 연동으로 교체할 수 있게 Service 계층은 분리해둘 것.

## 3. 프론트엔드 요구사항

### 3.1 폴더 구조 (백엔드와 미러링)

```
src
 ├─ main.jsx
 ├─ App.jsx                 (Router 정의)
 ├─ layouts/MainLayout.jsx  (Sidebar + Header + <Outlet/>)
 ├─ components/Sidebar.jsx  (아래 3.3 디자인 사양 참고)
 ├─ api
 │   ├─ axiosInstance.js
 │   ├─ menuApi.js
 │   ├─ base/, monitoring/, production/, condition/, quality/, equipment/
 ├─ pages
 │   ├─ base/, monitoring/, production/, condition/, quality/, equipment/
 │       (각 폴더 안에 소속 메뉴 개수만큼 컴포넌트, 1단계에서는 "메뉴명 + 준비중" 정도의 placeholder 내용만)
 └─ router/routes.js
```

### 3.2 라우팅

- 백엔드 메뉴 API의 `path` 값을 React Router 경로로 그대로 사용
- 사이드바 클릭 → `navigate(path)` → 해당 페이지 렌더링까지가 1단계 완료 기준
- 예: `/base/user` 클릭 → `pages/base/UserManagement.jsx` 렌더링

### 3.3 사이드바 디자인 사양

- 좌측 고정 사이드바, 다크 톤(#15171c 배경)
- 상단 토글 버튼 클릭 시 사이드바 접기/펼치기 (아이콘만 남는 형태로 축소)
- 대분류(카테고리)는 아코디언으로 펼침/숨김
- 메뉴 클릭 시 활성 상태 하이라이트(좌측 accent 바 + 배경색)
- 스크롤바는 시각적으로 숨기되 휠 스크롤은 동작

                        onMouseEnter={e => { if (!active) { e.currentTarget.style.background = 'rgba(255,255,255,.035)'; e.currentTarget.style.color = '#d1d5db'; } }}
                        onMouseLeave={e => { if (!active) { e.currentTarget.style.background = 'transparent'; e.currentTarget.style.color = '#9199a8'; } }}
                      >
                        {item.name}
                      </button>
                    );
                  })}
                </div>
              )}
            </div>
          );
        })}
      </div>

      {/* 하단 사용자 정보 */}
      <div style={{ padding: '12px 16px', borderTop: '1px solid rgba(255,255,255,.06)', display: 'flex', alignItems: 'center', gap: 10 }}>
        <div style={{
          width: 26, height: 26, borderRadius: '50%', background: '#2a2d35', flexShrink: 0,
          display: 'flex', alignItems: 'center', justifyContent: 'center', fontSize: 11, fontWeight: 500, color: '#9ca3af',
        }}>
          {userInitial}
        </div>
        {!collapsed && (
          <div style={{ overflow: 'hidden' }}>
            <div style={{ fontSize: 12, color: '#e5e7eb', whiteSpace: 'nowrap' }}>{userName}</div>
            <div style={{ fontSize: 11, color: '#6b7280', whiteSpace: 'nowrap' }}>{userDept}</div>
          </div>
        )}
      </div>

      <style>{`
        .mes-sidebar-scroll::-webkit-scrollbar { display: none; }
        .mes-sidebar-scroll { scrollbar-width: none; -ms-overflow-style: none; }
      `}</style>
    </div>
  );
}
